# 线性筛

代码：

```cpp
#include <bits/stdc++.h>

using namespace std;

const int N = 1e6 + 10;

int primes[N], cnt;
bool st[N];

void prime_cnt(int x){
    for (int i = 2 ; i <= x ; i ++) {
        if (!st[i]) primes[cnt++] = i;
        for (int j = 0 ; primes[j] <= x/i ; j ++) {
            st[primes[j] * i] = true;
            if (i%primes[j]==0) break;
        }
    }
}

int main(){
    int n;
    scanf("%d", &n);
    prime_cnt(n);
    printf("%d", cnt);
    return 0;
}
```

我的理解：

目的：过去的一些埃及里德算法在筛质数的过程中，会出现重复筛掉部分合数的情况。线性筛可以保证每一个合数只被筛一次。

基本想法：一个合数可以被分解为一个最小质因子 `p` 和一个最大因子 `i`，所以我们可以使用唯一的一个二元组去筛掉所有的合数。

具体流程：在线性筛的过程中，我们会从 2 开始，首先是记录所有的质数 `primes[cnt++]`。对于当前数 i，我们有如下的操作：

遍历小于 i 的所有质数 `primes[j]`，筛掉以 `primes[j]` 作为最小质因数的 `primes[j] * i`。

这里可以分两种情况讨论：

- 当 `i` 是质数的时候：很显然最后一个循环会一直遍历到 `i` 这个质数，对应的 `primes[j] * i` 的最小质因数显然是 `primes[j]`。

- 当 `i` 是合数的时候：我们需要保证的是 **`primes[j]`一定是 `primes[j] * i` 的最小质因子**。在第一次遇到 `i % primes[j] == 0` 之前，显然 `primes[j]` 一定是最小质因子。一旦遇到 `i % primes[j] == 0` 的时候，意味着 `i` 本身的最小质因子为 `primes[j]`，假设我们继续遍历 `primes[j+1]`，则此时的 `i * primes[j+1] = k * primes[j] * primes[j+1]`，显然最小质因数不是 `primes[j+1]` 而是 `primes[j]`，违背了我们的基本思想，所以停止。
